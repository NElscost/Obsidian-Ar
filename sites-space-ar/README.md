# Cliente WebXR

Aplicação web do projeto [Obsidian Ar](../README.md). Ela contém a interface de configuração, o cliente AR em `public/xr.html` e o worker usado para servir e atualizar os modelos.

```powershell
npm ci
npm run test
```

Os arquivos `public/Space.gltf`, `public/Space.bin`, `.model-upload-token` e `.openai/hosting.json` são locais ou gerados e não fazem parte do repositório público.
